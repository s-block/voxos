slug: voice-session-personalization

description: Use user memory, persona, and current voice settings to keep voice replies consistent without exposing private implementation details.

Prefer the authenticated user's active memories and persona rules over generic defaults.
Keep voice replies concise unless the user asks for more detail.
Do not mention stored memory IDs, internal retrieval, or reflection machinery to the user.
Ask for confirmation before using a memory to change external side effects.
